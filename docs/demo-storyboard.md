# MCC 介绍视频分镜(约 2 分钟 · 手机竖屏)

样片不随包,挂在 GitHub Release:https://github.com/Sebastilan/mccv2-lite/releases/download/v0.1.0/mcc-demo.mp4 (2 分 08 秒,中文配音 + 中英字幕,1080 宽高清,手机视口自动真点录制,全程真实速度、没有剪辑;README 里的 docs/demo-preview.gif 是它的 4 倍速预览)。下面的镜头表就是照样片排的,重录时照着走。

## 一、手机上比电脑还方便的地方(按这些点排镜头)

| # | 方便在哪 | 电脑上要怎么做 | 镜头 |
|---|---|---|---|
| 1 | 打开浏览器就能用,可添加到主屏幕;AI 跑在服务器上,合上电脑、锁屏、换网络都不中断,断线后自动补发 | 守在电脑前,开着终端窗口 | S2 / S6 |
| 2 | 一屏看全部终端:卡片显示状态(空闲 / 执行中 / 等使),按「君 · 臣 · 使」分层,派出去的小工挂在「使」下面 | 开一堆终端窗口来回翻 | S3 |
| 3 | 终端内顶部 Tab 栏一点就切,进场前已预取好,切过去立刻有内容 | Alt-Tab 找窗口,或记 tmux 快捷键 | S4 |
| 4 | 找文件:工作区文件树,点开就预览,看中了直接「批注此文件」 | ssh 上去 ls、cat,或者先下载再打开 | S5 |
| 5 | 派活一句话;要补材料就直接发相册图片(自动压缩);`/` 命令面板切模型;`@` 叫另一个终端协作 | 打字、找文件路径、复制粘贴 | S6(可加 S6b) |

**可插镜头**(想加功能点时用,每个约 8–10 秒,总长控制在 2 分钟内可删 S4 或缩短 S8 的等待):
- S6b 发图派活:点「+」从相册选一张白板照片,「按这张图整理成待办」。
- S6c 问答卡:「先问我要 3 页还是 5 页」→ 屏上出现两个按钮 → 点「3 页」→ AI 接着干(已验证可用)。

## 三、录制提示

- 用真机录:手机系统自带录屏,竖屏;提前把浏览器「添加到主屏幕」,录出来没有地址栏更像 App。
- 先把场景准备好:三个终端(讲座稿=君、客户调研=臣、找配图=使,挂在客户调研下面;新版新建终端不选项目,都在共用工作区里,样片录于选项目的旧版),「讲座稿」先跑一小轮留点历史。开录后再给「客户调研」「找配图」派活,总览上才是「执行中」。
- 模型选 Sonnet:出活快,S6、S8 两段等待各约 20 秒;用 Opus 会更慢,后期可以 2–4 倍速快进。
- AI 偶尔会用英文写过程说明,碰上就重录这一段,或在派活那句末尾加「用中文回复」。
- 字幕在样片里是录制时叠加的;真机重录时用剪映按上表加字幕即可。
